CASE STUDY / 01

SAML 2.0 Single Sign-On

A practical implementation of federated sign-in across service-provider and identity-provider roles.

Problem space

Enable a user to move between an application and an identity provider without repeating credential entry, while validating the trust and integrity of the SAML exchange.

Implementation highlights

  • Built SP→IdP and IdP→SP flows, including SAML request/response handling.
  • Generated SAML metadata for entity details, endpoints, and certificates.
  • Managed X.509 certificates and used digital signatures with verification of incoming SAML responses.
  • Documented ADFS integration in the public repository.

Flow

Service Provider→ AuthnRequest →Identity Provider→ signed response →Validation

CASE STUDY / 03

SmartReactor Review Responder

A retrieval-assisted AI tool for drafting empathetic, context-aware responses to app reviews.

How it works

Review text→ retrieve →FAQ matches→ generate →Draft reply

Implementation highlights

  • Loads FAQ content and uses embeddings with FAISS for semantic matching.
  • Combines the review and relevant FAQ context in a prompt to generate a response.
  • Provides a lightweight Flask interface for manual testing.
  • Separates FAQ loading, vector search, and response generation into Python modules.
